# 🎓 SMK — Siap Masuk Kerja
> *"Simulasikan Seleksi. Tingkatkan Kesiapan"*

Platform simulasi persiapan tes kerja komprehensif berbasis web/mobile untuk lulusan SMA/SMK yang mempersiapkan diri memasuki dunia industri manufaktur, otomotif, dan logistik (PT Astra Daihatsu, PT Epson Indonesia, PT Yamaha Motor, PT Denso, PT Mayora Indah, dll.).

---

## 🚀 Fitur Unggulan

1. **📑 Simulasi Tes Kraepelin & Pauli (Tes Koran):**
   - Perhitungan psikometrik presisi: Panker (kecepatan), Janker (ketelitian), Tianker (stabilitas), dan Hankan (ketahanan).
   - Numpad sentuh ergonomis (100% Zero-Scroll di layar HP).

2. **⚡ Tabel Perkalian Berurutan (1×1 s/d 10×10 - Durasi 2 Menit):**
   - Papan tombol angka responsif.
   - Deteksi kecepatan hitung mental dan peta matriks 100 kisi perkalian visual.

3. **🔢 Matematika Dasar & Konversi Satuan (1.000+ Soal Acak Dinamis):**
   - Pilihan paket soal: 10, 30, 50, dan 100 soal dengan durasi standar industri terkunci.
   - Generator parametrik dinamis (Kabataku, pecahan, aljabar, persen, perbandingan shift, konversi panjang, berat, volume, waktu, kuantitas).

4. **🧠 Psikotes Penalaran & Logika:**
   - Bank soal sinonim, antonim istilah industri, analogi logika, dan silogisme deduktif kepatuhan SOP pabrik.

5. **⚙️ Tes Mekanika Bennett:**
   - Diagram visual SVG interaktif untuk roda gigi beruntun (CW/CCW), katrol majemuk, dan tuas pengungkit.

6. **🔍 Tes Ketelitian Barcode & Kode QC:**
   - Speed match 45 detik mendeteksi 1 karakter anomali/cacat reject (NG).

7. **🎨 Kanvas Tes Wartegg (8 Kotak):**
   - Panduan menggambar stimulus psikodiagnostik kepribadian kerja.

8. **🎙️ AI Voice Mock Interview HRD:**
   - Evaluasi metode STAR, deteksi filler words, dan kalkulasi probabilitas kelulusan kerja.

9. **💻 Dashboard Admin Command Center:**
   - Monitoring live aktivitas pengerjaan peserta, analisis rapor, dan parameter bank soal.

## 🛠️ Teknologi yang Digunakan

- **Frontend:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + Lucide React Icons
- **Visuals & Effects:** Canvas Confetti + Web Audio API Synthesizer
- **State Management:** React Hooks

## 💻 Cara Menjalankan Aplikasi Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/enjangjahrudin/siapmasukkerja.git
   cd siapmasukkerja
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Jalankan development server:**
   ```bash
   npm run dev
   ```

4. **Buka di browser:**
   Akses `http://localhost:3000` (atau port yang tertera pada terminal).

5. **Build untuk produksi:**
   ```bash
   npm run build
   ```
